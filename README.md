# 한국어 개인용 TodoList 웹앱

> 하루의 할 일을 빠르게 추가하고, 완료하고, 정리할 수 있는 깔끔하고 완성도 높은 개인용 TodoList 웹앱입니다.  
> React, TypeScript, Vite, CSS Custom Properties(디자인 토큰 기반)로 구현되었습니다.

---

## 1. 주요 기능

1. **할 일 추가**
   - Enter 키 또는 '추가' 버튼으로 신속 등록
   - 앞뒤 공백 자동 제거 및 빈 문자열/공백 전용 입력 차단
   - 최대 200자 제한 및 실시간 글자 수 안내
   - 한글 IME 조합 중 Enter 시 조기 등록 방지 (`isComposing` 처리)
   - 추가 후 입력창 초기화 및 포커스 유지
   - 최신 항목 맨 위 배치 (`createdAt` 내림차순 정렬)

2. **완료 상태 관리**
   - 접근 가능한 체크박스 기반 토글
   - 완료 항목에 명확한 취소선 및 Muted 색상 구분 (전체 투명도 감소로 버튼이 흐려지는 현상 방지)
   - 상단 진행률 바 및 퍼센트(%) 실시간 동기화 (할 일이 0개일 때 0% 오류 방지)

3. **인라인 내용 수정**
   - '수정' 버튼 클릭 시 인라인 편집 모드 전환
   - Enter 키 또는 '저장' 버튼으로 반영, Esc 키 또는 '취소' 버튼으로 취소
   - 한글 IME 조합 중 Enter 처리
   - 수정 완료/취소 시 원래의 수정 버튼으로 포커스 자동 복귀

4. **개별 삭제 및 실행 취소**
   - 항목 삭제 시 하단 플로팅 토스트("할 일을 삭제했어요.") 제공
   - '실행 취소' 클릭 시 원래 ID, 내용, 완료 여부, 등록 시각 및 원래 정렬 위치 복원
   - 연속 삭제 시 최신 삭제 1건이 실행 취소 대상임을 명확히 보장
   - 삭제 후 다음 항목의 삭제 버튼으로 포커스 자동 이동 (접근성 고려)

5. **상태 필터 및 실시간 검색**
   - 상태 필터: '전체', '진행 중', '완료' (`aria-pressed` 지원)
   - 검색창: 부분 일치 및 대소문자 무시 검색, 검색어 지우기 기능 제공
   - 필터와 검색 조건의 교집합 적용
   - 전체 데이터 없음 / 검색 결과 없음 / 조건별 빈 상태를 명확히 구분하여 전용 피드백 제공
   - 현재 필터 조건 때문에 새로 추가되거나 복원된 항목이 숨겨진 경우 "전체 보기" 알림 배너 제공

6. **완료 항목 일괄 삭제**
   - 완료 항목이 없을 때 비활성화 (`disabled`)
   - 네이티브 `<dialog>` 기반 확인 모달 제공 (삭제 대상 개수 명시)
   - Esc 키 또는 취소 시 안전하게 데이터 유지

7. **디자인 및 반응형 레이아웃**
   - `DESIGN.md` 단일 원천 CSS Custom Properties 디자인 토큰 적용
   - 360px 모바일, 768px 태블릿, 1440px 데스크톱 완벽 지원
   - 긴 한국어 문장 및 공백 없는 긴 영문 문자열 줄바꿈 (`overflow-wrap: anywhere;`)
   - 주요 조작 영역 44px 이상 터치 타깃 확보 및 4.5:1 이상 텍스트 명도 대비

## 2. 저장 방식 및 제한사항

- **저장 위치**: 현재 사용 중인 웹 브라우저의 `localStorage` (키: `todo-app:v1`).
- **스키마 버전 관리**: `schemaVersion: 1` 객체 구조로 관리되며 데이터 손상 및 상위 버전 스키마 감지 시 덮어쓰기를 방지합니다.
- **제한사항**:
  - 본 애플리케이션은 순수 클라이언트 기반 로컬 웹앱입니다.
  - **계정 로그인, 클라우드 동기화 및 백업 기능이 제공되지 않습니다.**
  - 다른 기기나 다른 브라우저와 데이터가 공유되지 않으며, 브라우저 캐시 및 사이트 데이터를 삭제하면 저장된 할 일이 초기화됩니다.
  - 여러 브라우저 탭에서 동시에 편집하는 경우 탭 간 실시간 병합을 지원하지 않습니다.
